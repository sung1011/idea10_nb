# 一起算

给约 5 岁孩子的 10 以内加减练习。打开即练，每轮 10 题；也可玩小动物坐车。大号键盘输入，答错可重试，做完有贴纸。设置里可看更新说明，并可安装到手机桌面；仍需联网，进度只在本机。

线上：https://sung1011.github.io/idea10_nb/

## 本地

```bash
npm install
npm test
npm run build
```

开发时在仓库根目录执行 `npx vite`，浏览器打开终端提示的地址（路径带 `/idea10_nb/`）。
